ARKED FARMASI - ZARIF ZAINOL (RPh 25633)
========================================

Isi folder:
  index.html          Laman utama (profil + koleksi game)
  games/              4 fail game (setiap satu ada kredit pencipta)
  img/                Gambar skrin game

MENAMBAH GAMBAR MUKA:
  Simpan gambar awak sebagai  img/foto-zarif.jpg  (gambar segi empat sama paling sesuai).
  Jika fail ini tiada, laman akan papar huruf "ZZ".

HOS PERCUMA DI NETLIFY:
  1. Daftar akaun percuma di https://app.netlify.com/signup
  2. Buka https://app.netlify.com/drop
  3. Seret SELURUH folder "portfolio-zarif" (bukan fail zip) ke kotak di halaman itu.
  4. Netlify beri alamat seperti  nama-rawak.netlify.app
  5. Tukar nama: Site configuration > Change site name, contohnya  arkedfarmasi-zarif

KEMAS KINI:
  Ubah fail dalam folder, kemudian di Netlify buka tab Deploys dan seret semula folder itu.
