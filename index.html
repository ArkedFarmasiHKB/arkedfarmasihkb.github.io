Koleksi Game

Pilih game, tekan Main online untuk terus bermain, atau Muat turun untuk simpan failnya.

Main di panel pintar

Setiap game ialah satu fail HTML. Tiada pemasangan diperlukan.

1

Muat turun

Tekan Muat turun pada game pilihan. Fail .html disimpan dalam folder Downloads.

2

Salin ke peranti

Pindahkan fail ke panel pintar atau komputer melalui pendrive, Google Drive atau WhatsApp.

3

Buka dengan Chrome

Tekan fail itu dan pilih Chrome. Gunakan butang skrin penuh jika ada, atau tekan F11 di komputer.

Tanpa internet, game tetap boleh dimain, tetapi huruf akan nampak lebih ringkas kerana fon dimuat dari internet.
